# data/

이 폴더의 데이터 파일은 **커밋하지 않는다**. `data/raw/`, `data/interim/`, `data/processed/`는 `.gitignore` 대상이고, 이 문서와 `manifest.json`만 추적한다.

## 규칙

1. 원본(`raw/`)은 수정하지 않는다. 가공 결과는 `interim/` → `processed/`로 단계별 저장한다.
2. 원본은 `python scripts/download_data.py`로 받는다. 받을 때마다 `data/manifest.json`(URL · 크기 · SHA-256 · 내려받은 시각)이 갱신되며, 이 파일은 커밋한다.
3. 신고 원문에는 개인정보가 섞여 있을 수 있다. 원문을 이슈 · PR · 커밋되는 노트북 출력에 붙여넣지 않는다.
4. 이용 조건(라이선스)은 데이터별로 확인해 아래 표에 적는다.

## 데이터셋

규모는 발표자료 기준이다.

| 이름 | 출처 | 내용 | 규모 | 파일 | 확인 상태 |
|---|---|---|---|---|---|
| `complaints` | NHTSA | 차종 · 연식 · 부품 · 신고일 · 사고/화재 · 주행거리 · 증상 글 | 원본 356MB 중 현대·기아 2015–2025 사용 | `FLAT_CMPL.zip` | URL 응답 확인 (2026-10-14) |
| `recalls` | NHTSA | 리콜일 · 차종 · 연식 · 부품 · 결함 요약 | 현대·기아 379건 (2014~) | `FLAT_RCL_POST_2010.zip` | URL 응답 확인 (2026-10-14) |
| `tsb` | NHTSA 제조사 공지 | 공지일 · 차종 · 연식 · 부품 · 수리 안내 요약 | 30MB (2020–2024 파일) | TODO | URL 미확인 |
| `kr_recalls` | 한국교통안전공단 (공공데이터포털) | 차명 · 생산기간 · 리콜개시일 · 리콜 사유 | 현대·기아 370건 (2017–2025) | TODO | URL 미확인 |

"URL 응답 확인"은 HEAD 요청에 200이 돌아왔다는 뜻이며 파일 내용은 아직 열어보지 않았다.
