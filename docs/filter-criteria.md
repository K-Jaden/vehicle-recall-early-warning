# 텍스트 사용 · 제외 기준 (Filter Criteria)

- 버전: **v0.0 (초안)** · 상태: **미동결**
- 목적: 신고 · 기술공지 텍스트 중 무엇을 LLM 점수화와 모델 입력에 쓸지 사전에 정의한다.
- 원칙: ① 예측 시점에 알 수 있던 정보만 ② 증상을 읽을 수 있는 글만 점수화 ③ 분석 단위(차종 × 연식 × 부품)에 귀속되는 글만 사용.
- 제외마다 사유 코드를 남기고, 단계별 잔존 건수표를 자동 집계한다.

## 1. 신고 텍스트 (3단계)

처리 구분: **전체 제외** = 건수 변수와 텍스트 점수 모두에서 뺀다 / **점수만 제외** = 신고 건수에는 포함하고 LLM 점수 대상에서만 뺀다.

| 단계 | 질문 | 사유 코드 | 기준 | 처리 |
|---|---|---|---|---|
| ① 시점 | 예측 시점에 알 수 있던 글인가 | `T1_AFTER_PREDICTION_TIME` | 접수일이 예측 시점 t 이후 | 전체 제외 |
| | | `T2_AFTER_RECALL` | 해당 단위의 리콜 발표 이후 접수 | 전체 제외 |
| | | `T3_MENTIONS_RECALL` | 본문에 "recall" · 캠페인 번호 언급 | TODO (파일럿 후 결정) |
| ② 품질 | 증상을 읽어낼 수 있는 글인가 | `Q1_EMPTY_OR_SHORT` | 빈 글 또는 최소 길이 미만 (임계값 TODO) | 점수만 제외 |
| | | `Q2_REDACTED_ONLY` | 삭제(redacted) 문구뿐인 글 | 점수만 제외 |
| | | `Q3_DUPLICATE` | 동일 본문 중복 제출 (판정 기준 TODO) | 전체 제외 |
| | | `Q4_NO_SYMPTOM` | 딜러 · 보증 · 금전 불만만 있고 증상 서술 없음 | 점수만 제외 |
| ③ 대상 | 분석 단위에 귀속되는가 | `U1_NOT_VEHICLE_PRODUCT` | 타이어 · 카시트 등 차량 외 제품 | 전체 제외 |
| | | `U2_OUT_OF_SCOPE_MAKE` | 현대 · 기아 외 | 전체 제외 |
| | | `U3_COMPONENT_UNMAPPED` | 부품 분류를 단위에 매핑할 수 없음 (규칙: `matching-rules.md`) | TODO |
